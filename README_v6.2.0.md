# ShiftControl v6.2.0
- Symetryczne zaokrąglenie pól daty na telefonie.
- Osobne pozycje 09:00 i Vakt.
- Vakt wybierany niezależnie, więc ta sama osoba może być na zmianie i jednocześnie na Vakt.
- Kenneth dostępny wyłącznie jako rezerwowa osoba do Vakt i nie wchodzi do automatycznej rotacji.
- Cała ramka daty na komputerze uruchamia natywny kalendarz przez showPicker, z mechanizmem zapasowym.
